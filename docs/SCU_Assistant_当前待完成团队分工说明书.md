## 一、编制依据

本文档基于 `docs/SCU_Assistant_团队具体分工说明书.docx` 中既定的团队分工，并结合当前代码仓库已经实现的功能状态，重新梳理每位成员在项目收尾阶段还需要完成的具体工作。

本次梳理依据包括：

1. 原分工文档中的组织结构：Team A 学业核心、Team B 生活服务、Team C 校园信息、AI 组、运维与测试、项目统筹。
2. 当前前端页面实现：登录、首页、每日简报、AI 对话、课表、成绩、DDL、考试、课件问答、AI 选课推荐、天气、通知、校车、校历、食堂、设置、AI 记忆管理等页面。
3. 当前后端接口实现：认证、教务数据、DDL、考试、AI 对话、RAG、智能出题、复习计划、天气、通知、每日简报、学习通、AI 记忆等接口。
4. 当前运行日志状态：后端 `/health`、验证码、登录、课表、成绩、培养方案、AI 对话流式接口等已有成功调用记录；真实教务系统已能抓取课表、成绩和培养方案数据。
5. 当前工程状态：本地启动脚本、Docker Compose、前后端 CI 配置已存在，但后端测试源码缺失，前端测试覆盖仍较少。

## 二、当前项目已实现功能概况

### 1. 已经基本落地的功能

当前项目已经完成了主要功能骨架和大部分核心链路：

- 认证与登录：支持教务系统账号登录、验证码获取、JWT 登录态、刷新 Token、退出登录、获取当前用户；前端登录页还支持学习通扫码登录入口。
- 教务数据：后端支持课表、成绩、培养方案完成度抓取与缓存；前端已完成课表页、成绩页、首页学业概览。
- DDL 与考试：后端支持 DDL CRUD、考试记录 CRUD、复习计划生成；前端已完成 DDL 追踪、考试倒计时和 AI 复习计划入口。
- 学习通集成：后端已实现学习通二维码、账号绑定、解绑、DDL 同步；前端在登录页、设置页和 DDL 页面均有相关入口。
- AI 对话：后端已实现普通对话、流式输出、LLM 意图路由、Tool Use；前端聊天页已支持流式展示和工具调用状态。
- RAG 与智能出题：后端支持知识库创建、文档上传、向量检索问答、基于知识库出题；前端课件问答页已支持知识库、上传、问答和出题 Tab。
- AI 选课推荐：后端可基于培养方案和成绩生成选课建议；前端有独立推荐页面。
- 天气穿衣：后端支持和风天气 API 与 Mock 降级；前端天气页和每日简报均有展示。
- 校园通知：后端支持教务处、学工部通知抓取、去重、刷新与 Mock 兜底；前端通知页已完成列表和来源筛选。
- 校园信息：前端已实现校车时刻、校历、食堂信息等页面，但这些页面目前主要采用前端静态数据。
- 每日简报与首页：后端支持聚合简报；前端已有首页学业概览和 `/dashboard` 每日简报页。
- 工程环境：已有本地无 Docker 启动脚本、Docker Compose、Conda/团队开发文档、前后端 GitHub Actions CI 配置。

### 2. 当前主要短板

项目当前不是从零开发阶段，剩余任务主要集中在“收口、验收、材料化”和少数“静态功能后端化”上：

- 食堂、校车、校历目前主要是前端静态数据，尚未形成统一后端接口和数据维护说明。
- 校园通知 README 中提到研究生院通知聚合，但当前真实爬虫主要覆盖教务处和学工部，研究生院更多体现为 Mock 数据来源。
- DDL、考试、RAG 等页面仍有若干 `TODO: toast` 或静默失败处理，错误提示和用户反馈需要补齐。
- 后端 `backend/tests` 目录目前只有 `__pycache__`，测试源码缺失；前端目前主要只有 Auth Store 测试，核心页面和接口封装测试不足。
- RAG/Quiz/Study Plan 等 AI 能力依赖 LLM 和 Embedding 配置，缺少完整的失败降级、演示样例和评估记录。
- 日志中存在 JWT 密钥长度不足警告，最终演示和交付前需要明确开发环境与生产环境密钥策略。
- 当前有首页 `/` 和每日简报 `/dashboard` 两套聚合视图，需要在演示口径中明确各自定位，避免答辩讲解重复。
- 代码、文档、PPT、周报、需求说明、系统设计说明之间还需要统一最终功能边界。

## 三、剩余工作拆分原则

1. 不推翻原分工，仍按原文档中的成员职责归口。
2. 已经实现的模块不再重复分配“从头开发”任务，重点转为验收、补漏、联调、文档和演示材料。
3. 优先级分为三类：
   - P0：答辩和最终交付前必须完成。
   - P1：建议完成，能明显提升稳定性和展示质量。
   - P2：有时间再做，可作为扩展优化。
4. 每位成员最终至少交付三类材料：功能状态说明、测试或联调记录、答辩截图或演示说明。
